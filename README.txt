Sanjita Sendang Limbu — Portfolio (plain HTML/CSS/JS version)
==============================================================

Files
-----
index.html   — the whole page (all text/content lives here)
styles.css   — all styling; edit colors in the :root block at the top
script.js    — small enhancements (scroll animations, active nav highlight)

How to use
----------
1. Open index.html in any browser — it works immediately, no tools needed.
2. To put it online, upload these three files to any static host
   (Netlify, Vercel, GitHub Pages, cPanel, etc.).

How to edit
-----------
- Your name, email, and project details are plain text inside index.html.
  Search for "Sanjita" or "sanjitasendang12" to find them quickly.
- Colors and fonts are at the top of styles.css in the :root section.
- Fonts load from Google Fonts; an internet connection is needed for the
  exact fonts (the page still works without them, using system fonts).
